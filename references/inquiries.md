# 联系表单与咨询接收

## 默认范围

新建官网默认具备联系表单、后台咨询管理和可选邮箱连接。后台数据库是主要接收端，没有联系电话或收件邮箱也应建立可用的咨询入口；不编造电话、邮箱或二维码。用户明确不要表单时按其范围交付。

## 访客表单

- 称呼、电话或邮箱、需求描述为必填；公司或品牌为选填，不默认索要附件、身份证等敏感资料。
- 简洁说明收集主体、合作沟通用途、保存及仅管理员查看，提供明确确认控件。不要编造回复时限。
- 服务端验证类型、长度、联系方式及同意状态；采用会话令牌、CSRF、防机器人隐藏字段、最低填写时间及服务端频率限制。使用可信直连 IP 或明确可信代理规则；不默认信任转发头，不保存原始 IP。
- 每次表单有不可预测的提交标识，数据库唯一约束保障重复提交不会重复新增。成功采用 POST 后跳转，显示确认编号；编号不能作为匿名读取咨询的凭据。
- 数据库事务提交成功才显示成功；数据库异常明确说明未保存并保留输入。表单页、失败页、成功反馈和管理页面禁止共享缓存，不能带入公开 ETag 或 sitemap。
- 联系入口从导航、页脚和相关详情可发现；桌面和手机的输入框、错误反馈、同意控件和提交按钮可触达。

## 后台咨询管理

- 独立“咨询管理”菜单，默认按提交时间倒序；显示待处理数量，提供搜索、状态筛选、分页、清除筛选和空状态。
- 详情包括提交编号、北京时间、称呼、联系方式、公司、需求、处理状态和内部跟进备注。
- 状态采用待处理、跟进中、已处理、垃圾咨询；读取不自动等于处理。保存返回真实结果，冲突保留输入，按咨询自己的版本检查并发修改。
- 永久删除前明确确认对象及不可恢复性；邮件正在处理的记录阻止删除。测试咨询用隔离标记，验收后清理，不计作真实线索。
- 查看和写入均需管理员鉴权；写操作校验 CSRF、枚举、长度及版本，SQL 参数化、HTML 转义。咨询不可进入公开页面、结构化数据、公开目录、日志正文或监测字段。

## 邮箱连接模块

- 默认关闭。日常界面只显示开启提醒、发件邮箱、邮箱授权码和接收邮箱；接收邮箱留空使用发件邮箱，授权码旁提供可展开的获取说明及官方帮助链接。
- 已核对的常见邮箱按完整域名自动匹配服务器、端口、加密方式，登录账号默认使用发件邮箱；前端提示与服务端匹配规则同源。不能仅凭企业自有域名猜测供应商。
- SMTP 主机、端口、加密方式与登录账号收进默认折叠的高级设置，勾选手动配置后才编辑。保留已有自定义连接，不能被自动匹配覆盖。
- 提供“保存设置”和“发送测试邮件”。测试使用明确说明的已保存配置，缺少必要配置时禁用并说明；保存不等于发送。测试需鉴权、CSRF、版本与频率限制，不创建咨询、不包含客户信息，不启用正式通知。
- 私有配置保存，密码不回显，留空保留旧值；更换发件账号或服务器不得将旧授权码自动转交新端点，需重新输入。配置修改有版本检查。
- 仅使用验证证书的 TLS / STARTTLS，不跳过证书校验。通知先进入数据库队列，发送在独立 CLI / 定时任务中进行，不阻塞访客请求、不决定保存成功与否。
- 状态区分未启用、等待发送、发送中、邮件服务器已接收、失败；配置已保存、服务器接收、实际送达和用户已读不能混同。
- 失败可人工重试，中断状态需明确提示送达待核对，避免自动重复发送。历史咨询不因启用配置而全部自动补发。
- 邮件默认只包含编号和后台链接，不含客户联系方式及需求正文。没有真实授权邮箱不发送测试邮件，也不声称送达验收通过。
- 发送任务由部署流程配置并验证，运行命令与故障定位放在维护文档或技术详情，不在日常表单堆放队列、脚本、定时任务术语。未部署发送任务时不得宣称自动通知可用，需在项目交付状态明确待办。

## 验收

实际浏览器执行提交咨询、查看成功编号、后台搜索详情、保存状态和备注、重新打开回读，检查桌面和手机。使用测试数据，不污染企业正式线索。另验证必填和非法联系方式、无同意、无 CSRF、重复提交、频率限制、并发版本、未登录访问和邮箱关闭时正常保存。邮件模块按配置条件分别记录协议检查、真实服务器连接与送达状态；未测项保留在项目私有验收记录，不能把代码存在当作成功。
